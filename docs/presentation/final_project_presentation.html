Context

What is Europe SFA?

🌍

Sales Force Automation (SFA)

PepsiCo's Salesforce deployment for European markets — promotions, customers, products, routing, and more. Think of it as the system of record for field sales data across countries.

📊

Why CSV uploads matter

When a market launches or updates data, teams don't type row-by-row in Salesforce. They prepare spreadsheet exports (CSV files) with hundreds or thousands of rows and bulk-upload them.

If you're not on the Europe SFA team: imagine shipping a product catalog to 20 countries — each country fills an Excel template, and every file must match Salesforce's exact rules or the whole upload fails.

Upload Paths

Two ways to load data into Salesforce

Data Import Tool (DIT)

  • PepsiCo's spreadsheet template tool for bulk loads
  • Friendly headers like *Promotion Name, *Market
  • Dates as DD/MM/YYYY
  • Used by market ops and data loaders

Salesforce Workbench

  • Alternative upload path via Salesforce API field names
  • Headers like Name, Market__c
  • Dates as YYYY-MM-DD
  • Often used by admins and technical loaders

Both paths validate against the same Salesforce org — but expect different column names and date formats. PepFlow supports both.

Broken Data

Missing required data & invalid picklists

Row *Promotion Name *Market *Promotion Type
16 (blank) RO In store
17 Blank Required Market (blank) Leaflet
8 Invalid Market NOT_A_MARKET Leaflet
10 Picklist Case RO leaflet

Picklists must match Salesforce exactly — including capitalization.

Why picklists break uploads

Salesforce stores allowed values like Leaflet, In store, RO. A typo or wrong case = instant rejection. Loaders often guess from a PDF template.

Required fields

Columns marked with * in DIT templates cannot be empty. Blank cells pass Excel review but fail at upload.

How PepFlow Fixes It

Date conversion
