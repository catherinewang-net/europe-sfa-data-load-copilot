My Approach

A guided path from upload to corrected CSV

Upload file → Detect template → Validate data → Suggest fixes → User approves → Download ready CSV

Supports both Workbench (API field names, YYYY-MM-DD) and Data Import Tool (friendly headers, DD/MM/YYYY) — validated against the same EUSFA metadata source.

5 / 12

Key Decisions

Design choices that keep the Copilot trustworthy

Data preparation, not Salesforce replacement

The Copilot prepares and validates CSVs before upload. Workbench and DIT remain the upload path.

EUSFA metadata as source of truth

Picklists, field types, required fields, and templates come from the local EUSFA Salesforce DX clone — read-only, never auto-modified.

Users stay in control

Safe fixes are proposed for approval. Risky changes — picklists, duplicates, scientific notation — require explicit user action. No auto-guessing picklist values.

Action-based fixes

Technical validation results are translated into clear, approvable corrections via Fix Issues in Copilot — in-app editing without leaving the workflow.

Capabilities

What the Copilot does

Header / template checks

Maps and validates headers against EUSFA template config for Workbench and DIT.

Date formatting

Detects ambiguous dates and converts to the correct format per upload method.

Picklist validation

Validates against metadata values — shows valid options, never auto-guesses replacements.

Whitespace cleanup

Trims leading/trailing spaces in phone, address, and identifier fields.

Leading zero protection

Preserves EAN, SKU, and route IDs that Excel strips or converts.

Duplicate detection

Flags duplicate external IDs and business keys before upload.

Data preparation warnings

Surfaces blocking vs. review items with clear readiness status.

Dual CSV download

Tool-Ready CSV for upload plus Review CSV with audit context.

Final Outcome

A working Copilot — ready for pilot use

What was built

  • Streamlit-based Copilot (streamlit run app.py)
  • Connected to local EUSFA Salesforce DX metadata
  • Full prepare → validate → approve → download workflow
  • Workbench and Data Import Tool upload paths

How it runs

  • Python 3.11+ with local EUSFA SFDX clone
  • Metadata refresh panel — fetch, compare, pull updates
  • Session metadata version lock with change warnings
  • 140+ automated tests covering core validators

The Copilot reads metadata from EUSFA_SFDX_REPO_PATH only. It never modifies Salesforce repository files or writes data to Salesforce.
